# What can be reproduced

`uv run pair-eeg reproduce-paper` reads the archived anonymous scores. It regenerates the participant means, SDs, exploratory paired tests, and two plots without training. The preserved table and comparison numbers are checked against `results/paper/` in automated tests.

`uv run pair-eeg train ...` starts a **new** run. Its default mode is `paper`, preserving the implementation operations where the archived code supports the chosen configuration. Exact historical training accuracy cannot be promised: seeds alone do not record the complete environment, the prior RNG history, or unsaved split indices.

## Paper and corrected modes

| Behavior | `paper` (default) | `corrected` |
| --- | --- | --- |
| Neural architectures and initialization order | Preserved, including constructor forward passes | Same architecture unless an input width requires the documented correction |
| Content SVM input | Always time-domain EEG, even if requested as PSD/DE; actual feature is recorded | Reads the requested raw/PSD/DE data |
| Python RNG for SVM | Historical omission of `random.seed` is preserved and warned about | Seeds Python, NumPy, and Torch |
| Neural output width | Derived from task; `legacy_output_classes` can explicitly encode an archived entry point's fixed width | Always derived from task; legacy override rejected |
| GLFNet-MLP local width | Five bands for content, four for state; incompatible inputs raise an explanatory error | Width follows the actual retained bands |
| Data windows and splits | Historical windows; 200/50 content split; state clips 0–199 / 200–249 with pairs together | Same scientific protocol; this mode does **not** introduce an independent test set |
| Per-input normalization | Torch sample SD for nonablated data, NumPy population SD after state ablation | Preserved |
| Training augmentation, Adam, label smoothing, early stopping | Preserved | Preserved |

Historical content SVM entries labeled PSD/DE were removed from the revised paper, not silently replaced by corrected runs. The available archived state GLFNet-MLP fixes its local width to four bands, so it cannot run the five-band full-spectrum configuration as supplied. Paper mode refuses that configuration; corrected mode can run it but cannot thereby reproduce or validate the historical full-band table number.

Some archived `main*.py` entry points fixed output dimensions before looping over tasks. The example configurations target the checked generic loop and explicitly selected settings; they are not a recovered manifest of every historical run. Set `legacy_output_classes` only when the actual old configuration is known. Invalid combinations should not be treated as new evidence about the paper.

## Randomness and recording order

The release's `recordings.csv` preserves the original sorted processing order after anonymization. Neural runs seed once before processing that ordered list. A constructor's dry forward pass can consume dropout random numbers and update batch-normalization buffers, so these passes were retained exactly. Data loaders keep the original shuffling, worker count, and augmentation behavior. Changing the number of workers, device, session selection, batch size, model, or preceding runs can change RNG consumption.

Running a sequence of configurations in separate processes is convenient but does not reconstruct an unknown historical sequence that shared one RNG stream. `scripts/run_suite.py` documents this explicitly. A recording limit is useful for debugging, not equivalent to running the entire original experiment.

The `train` extra locks CPU Torch 2.5.1; `cuda` locks CUDA 12.1 Torch 2.5.1. The extras are mutually exclusive. CUDA driver, GPU architecture, cuDNN, BLAS, and dependency details remain part of the environment. `strict_determinism = true` enables stricter Torch checks; it is off in paper mode by default because introducing new algorithm choices would not preserve the old execution settings.

New runs save configuration, effective feature, package/device versions, per-recording RNG states, train/validation indices, epoch metrics, best-model parameters, and validation predictions. Existing output directories are rejected. RNG files are Torch/Python serialization artifacts generated by your own run and should not be loaded from untrusted sources.

## Real-data parity check

The authors ran `scripts/compare_real_experiments.py` on the first anonymous recording with seed 42 and up to 400 epochs (patience 40) on an NVIDIA L40. Raw EEGNet content decoding, PSD MLP content decoding, and DE MLP state decoding stopped after 46, 67, and 84 epochs, respectively. In all three cases the legacy and refactored implementations had identical split indices, every recorded epoch metric, best checkpoint tensor, and best validation score. The scores were 8.0%, 28.0%, and 98.0%, respectively. The first two differed from the corresponding archived session entries (12.0% and 36.0%); the DE state score matched its archived 98.0% entry. The causes of the archive discrepancies have not been established; complete historical configuration, RNG, and environment provenance is unavailable. This check demonstrates implementation parity for these selected runs, not reconstruction of the historical tables or the full 20-participant experiment. The existing CUDA environment used PyTorch 2.5.1+cu121 and torch-geometric 2.5.1; it is documented in `results/parity/real-data-comparison.json` and differs from the locked CPU test environment.

## Verification performed

In a locked Python 3.11 CPU environment, regression tests compare the refactored implementation with the frozen legacy source:

- Ten model/configuration cases: identical state dictionaries after initialization, identical constructor RNG state, identical logits and loss, and identical parameters after one Adam update (`rtol=0`, `atol=0`).
- Raw/PSD/DE content labels, normalization, Gaussian augmentation, and random partitions.
- Full/ablated raw/PSD/DE state inputs, including crop, band removal, dtype, and SD conventions.
- A two-epoch synthetic MLP run with 0 and 2 workers: identical accuracy and final Python/NumPy/Torch RNG state, with saved split/prediction provenance.
- Archived statistics: numerical agreement within `1e-13` for CSV numerical values.

These are short correctness checks on synthetic inputs, not new scientific training runs. No complete 20-participant retraining or GPU equivalence run was performed. Validation selection bias and lack of eye-tracking/cross-subject controls remain scientific limitations.
